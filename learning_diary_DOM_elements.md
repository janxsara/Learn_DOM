# DOM-Tagebuch

- Mit document greife ich auf die HTML-Seite zu.
- Mit getElementById finde ich ein Element.
- Mit textContent ändere ich den Text.

## Task 2

- Mit getElementById finde ich die Liste myList.
- Mit createElement erstelle ich einen Listeneintrag.
- Mit appendChild füge ich ihn zur Liste hinzu.

## Input

- Ein input ist ein Eingabefeld.
- Mit value lese ich den eingegebenen Text.
- Mit placeholder ändere ich den Hinweistext.
- Mit disabled kann ich das Feld deaktivieren.
- JavaScript muss erst starten, wenn die HTML-Elemente geladen sind.

## Button

- textContent ändert die Beschriftung.
- disabled deaktiviert den Button.
- type bestimmt die Funktion des Buttons.

## Div

- Ein div ist ein Bereich auf der Seite.
- textContent verändert seinen Text.
- Mit style ändere ich Farbe und Abstand.

## Table

- Eine table stellt Daten in Zeilen und Spalten dar.
- Mit insertRow füge ich eine Zeile hinzu.
- Mit insertCell füge ich eine Zelle hinzu.
